# A Family Scene — The Last Dumpling

One short family scene (one line, 184 characters) for the "Make the AI Judge
Feel Proud" bounty: at the kitchen table, Grandma slides the last dumpling
toward her grandchild and treats the family recipe like a state secret —
warm, a little funny, and specific.

`main.ts` (Node 22, standard library only) writes the scene to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), validates it against
the gate (1–2 lines, 1–280 characters, not only whitespace) before and
after writing, and is deterministic — two runs produce byte-identical output.
